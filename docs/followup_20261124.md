Build the data first (generated data is not committed; `per_field.csv` is on branch
`docs/hd-epic-four-model-baseline-20261110`):

    git show origin/docs/hd-epic-four-model-baseline-20261110:results/hd_epic_q40_v1_four_model_baseline_20261110/per_field.csv > /tmp/per_field.csv

`data/hd_epic_argon_novideo_v1/k{4,8,16,32}` then reproduce the Argon baseline calls exactly (same questions,
order and grouping; built from the four-model `per_field.csv` with
`scripts/build_hd_epic_argon_novideo.py`). Configs match the baseline's generation settings via the new
`generation.thinking_level` (MEDIUM, 32,768 tokens; no temperature was set in the baseline).

    for k in 4 8 16 32; do video-report run --config experiments/hd_epic_argon_novideo/k$k/config.yaml; done

(direct Vertex Global); check that `thinking_level` reaches the API on the first call (google-genai
