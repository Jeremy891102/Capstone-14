# CC4D 答案題型實驗:pilot 結果

日期:2026-11-02。對象:兩段錄影(1_32,6.0 分;16_42,15.8 分),549 個 call,每個模型各跑一次(並行數 1,fps 2,480p)。

## 1. 結論

- **Flash-Lite 大部分格子接近亂猜**,只跑它的話,題數與題型的效應很難偵測。
- **3.6 Flash 明顯較強**(整體 60% 對 37%),但兩端都有問題:定位題接近滿分,錯誤列的整數、複選、單選仍在亂猜水準。
- **建議兩個模型都跑**:Flash-Lite 是便宜的基準,3.6 Flash 是主要結果。總預算約 US$870。

## 5. 定位時間點

- 預測與真實的相關係數 **0.91**,中位數誤差 17 秒(目標中位數 417 秒)。
- 斜率:16_42 為 1.20,1_32 為 1.07。Flash-Lite 約 1.6 倍拉長,3.6 Flash 基本消失。
- 少數預測仍超過影片長度(最大 1526 秒,影片 948 秒;537 秒,影片 359 秒)。
- 1.6 倍拉長已排除 fps、片段長度、標註錯位,屬模型行為(原因未確認)。

## 7. 已知問題

1. 複選題把 `not_visible` 寫進清單(`["not_visible"]`),3.6 Flash 約 4% 無效。待修:提示詞。
2. 是非題預測偏向:時長 是非 False 214 / True 65 / not_visible 13;錯誤 是非 False 57 / True 41。
3. 評審還沒驗證:需要標約 100 題 open_text(`scripts/judge_agreement.py`)。
4. 只有兩段錄影,格子差異的信賴區間很寬。
