# Q5:題型和題數會不會影響幻覺?沒做的步驟在 call 裡的位置有關係嗎?

模型:Gemini 3.5 Flash-Lite、Qwen3-VL-32B(Argon 沒有跑這些題組)。資料:`cc4d_answer_types_v1` 的 not_done(k = 1)、h4、h8(k = 4、8,正序與倒序)與 E5 的對應題組(k 到 16)。
腳本:`results/cc4d_q5.py`;完整輸出:`results/cc4d_q5_out.txt`。

## 大綱與結論

| 子問題 | 結論 |
| --- | --- |
| 5.1 不同題型的幻覺率 | **題型影響很大,而且兩個模型的排名不同。** Flash-Lite 在 loc bool(97%)、err open_text(88%)、err bool(85%)最糟,loc single(27%)最好;Qwen 在 err multi(91%)、dur seconds(89%)最糟,err bool(37%)與 err open_text(45%)最好 |
| 5.2 題數對幻覺的影響 | **兩個模型方向相反。** Flash-Lite 的幻覺率隨題數下降(66% → 50% → 52%),代價是更常說「看不到」(誤判沒做 2.9% → 6.4%);Qwen 的幻覺率隨題數小幅上升(70% → 74% → 77%) |
| 5.3 沒做的步驟在 call 裡的位置 | **沒有明確的位置效應。** Flash-Lite 沒有;Qwen 後面的位置略高(k = 8:74% → 82%),但不顯著(p = 0.098) |
| 5.4 call 裡放進沒做的步驟,會影響其他題嗎? | **幾乎不會。** 其他題的準確率變化都在 ±1.1 pt 內,只有兩格區間剛好不含 0 |
| 5.5 error 內容的誤報(沒錯的步驟被說成有錯) | **誤報率隨題數下降**:題數越多,兩個模型越傾向答「沒有錯」 |

**一句話總結:** 幻覺率主要由題型決定,兩個模型各有最糟和最好的題型;題數增加對 Flash-Lite 有幫助(但同時更常把有拍的步驟說成沒做),對 Qwen 沒有幫助,甚至小幅更糟;沒做的步驟放在 call 的哪個位置沒有明確差別。

## 方法

- **沒做的步驟:** 食譜裡有、但影片中沒有拍到的步驟(Missing Step)。每一題都允許答 `not_visible`,對沒做的步驟,`not_visible` 是正確答案。
- **幻覺率:** 沒做的步驟被回答成 `not_visible` 以外任何有效答案的比例。分母只含有效答案(排除格式錯誤的答案,約 4%),所以數字和先前 Qwen 分析(73% / 73% / 77%,分母含無效答案)略有不同。
- **誤判沒做(false not-done):** 有拍到的步驟被回答成 `not_visible` 的比例。
- **E1(k = 1):** 108 個沒做的步驟 × 11 個格子,每題單獨問。
- **H batch(k > 1):** 把原本 batch 裡的一題換成同一份報告的沒做步驟,其他題不變;被換的位置在各報告間輪替,k = 4 與 8 共涵蓋所有位置。
- **跨 k 比較:** 5.2 只用在 k = 1、4、8 都有出現的同一批沒做步驟(Flash-Lite 與 Qwen 各約 500 題),正序。
- **信賴區間:** 依錄影 bootstrap 2,000 次。
- **回歸:**
  - 題數(5.2):邏輯斯回歸 `hall ~ log2(k) + cell`;依變項 `hall` = 是否為幻覺,`cell` = 內容 × 題型。
  - 位置(5.3):`hall ~ posfrac + log2(k) + cell`,`posfrac` 是沒做的步驟在 call 內的相對位置(0 = 第一題,1 = 最後一題)。
  - 標準誤依錄影群集。
- 沒有多重比較校正。

## 5.1 不同題型的幻覺率(k = 1)

**結論:** 題型影響很大,但兩個模型的排名不一致。沒有「哪一種題型一律最容易幻覺」。

![q5_by_type](figs/q5_by_type.png)

| 格子 | Flash-Lite | Qwen |
| --- | --- | --- |
| 全部 | 67.4% [61.5, 73.2] | 70.4% [63.3, 76.8] |
| dur bool | 74.1% | 63.0% |
| dur single | 51.9% | 64.8% |
| dur seconds | 51.9% | 88.9% |
| err bool | 85.2% | **37.0%** |
| err single | 69.7% | 74.1% |
| err multi | 64.0%(n = 75) | **91.3%** |
| err int | 72.2% | 87.0% |
| err open_text | **88.0%** | **45.4%** |
| loc bool | **97.2%** | 66.7% |
| loc single | **27.1%** | 70.4% |
| loc seconds | 58.9% | 86.1% |

- Flash-Lite 的 loc bool 97%:幾乎不會說「看不到」。loc single 27% 最低,原因我沒有進一步確認。
- Qwen 在 err bool、err open_text 較不會幻覺,但這兩格正是它「一律答沒有錯」的格子(見 Q2),所以不能解釋成「比較會判斷」。
- Flash-Lite 的 err multi 只有 75 題有效答案(33 題格式錯誤),這一格的估計較不穩。

**誤判沒做(有拍的步驟被說成看不到),k = 1:** Flash-Lite 整體 2.9%,loc single 最高(13.9%),其他格子都在 2.3% 以下;Qwen 整體 4.3%,err open_text 17.4%、err bool 10.5% 最高,其他多在 5% 以下。幻覺率低的格子,誤判沒做通常也較高,代表模型是用「更常說看不到」換來較低的幻覺率。

## 5.2 題數對幻覺的影響

**結論:** 兩個模型方向相反。Flash-Lite 的幻覺率隨題數下降,但誤判沒做同時上升;Qwen 的幻覺率隨題數小幅上升。

![q5_by_k](figs/q5_by_k.png)

(同一批沒做的步驟在每個 k 都有;右圖是有拍的步驟被答成 `not_visible` 的比例。)

| 模型 | k = 1 | k = 4 | k = 8 | 每加倍 k 的 log-odds [95% CI] |
| --- | --- | --- | --- | --- |
| Flash-Lite 幻覺率 | 65.8% [58.9, 73.3] | 50.4% [41.8, 60.2] | 52.4% [44.2, 60.8] | **−0.246** [−0.332, −0.160] |
| Qwen 幻覺率 | 70.3% [61.0, 78.8] | 73.5% [63.5, 82.7] | 76.7% [68.6, 84.5] | **+0.113** [+0.044, +0.181] |
| Flash-Lite 誤判沒做 | 2.9% | 6.1% | 6.4% | — |
| Qwen 誤判沒做 | 4.3% | 4.5% | 4.8% | — |

**依題型(k = 1 → 4 → 8,同一批步驟):**

| 題型 | Flash-Lite | Qwen |
| --- | --- | --- |
| bool | 91% → 69% → 72% | 60% → 64% → 68% |
| single | 50% → 32% → 35% | 69% → 73% → 75% |
| multi | 50% → 41% → 42% | 90% → 86% → 83% |
| int | 62% → 52% → 68% | 83% → 88% → 98% |
| open_text | 91% → 70% → 62% | 51% → 57% → 62% |
| seconds | 44% → 39% → 38% | 83% → 84% → 86% |

- Flash-Lite 下降最多的是 bool 與 open_text;Qwen 上升最多的是 int(83% → 98%)。
- Flash-Lite 的 single 誤判沒做從 6% 升到 12%,是它「更保守」最明顯的格子。

**E5(影片更長,k 到 16,正序):**

| 模型 / 內容 | k = 1 | k = 4 | k = 8 | k = 16 |
| --- | --- | --- | --- | --- |
| Flash-Lite loc | 81% | 64% | 65% | 62% |
| Flash-Lite dur | 61% | 40% | 43% | 53% |
| Qwen loc | 94% | 89% | 88% | 83% |
| Qwen dur | 95% | 96% | 97% | 97% |

- E5 的沒做步驟很少(每格 24 到 144 題),只能看趨勢。Flash-Lite 在 k = 16 的 dur 又回升到 53%,不是單調下降。Qwen 的 loc 隨題數下降,dur 幾乎全在 95% 以上。

## 5.3 沒做的步驟在 call 裡的位置

**結論:** 沒有明確的位置效應。

位置是在 H batch 裡的位置(k = 4 與 8,正序與倒序合併):

| 模型 | posfrac 係數 [95% CI] | p | k = 8 各位置(1 到 8)的幻覺率 |
| --- | --- | --- | --- |
| Flash-Lite | −0.007 [−0.154, +0.140] | 0.93 | 54 / 48 / 50 / 52 / 50 / 47 / 56 / 57% |
| Qwen | +0.153 [−0.028, +0.333] | 0.098 | 74 / 74 / 76 / 78 / 82 / 80 / 82 / 80% |

![q5_by_position](figs/q5_by_position.png)

- Qwen 的後面位置略高(74% → 80 到 82%),但區間含 0。k = 4 沒有這個趨勢(76 / 70 / 69 / 77%)。
- **未做的部分:** 提案還想看「沒做的步驟在食譜中的位置(離影片結尾多遠)」。資料裡的步驟編號是跨食譜的全域編號,不是食譜內的順序,要做需要另外對照食譜的步驟順序,這次沒有做。

## 5.4 call 裡放進沒做的步驟,會影響其他題嗎

**結論:** 幾乎不會。H batch 裡其他 k − 1 題與原本 batch 的同一題相比,準確率變化都在 ±1.1 pt 內。

| 模型 / k / 順序 | 變化(pt) [95% CI] | 對→錯 | 錯→對 |
| --- | --- | --- | --- |
| Flash-Lite k = 4 正序 | −0.3 [−1.3, +0.8] | 210 | 201 |
| Flash-Lite k = 4 倒序 | **−1.1 [−2.2, −0.1]** | 216 | 182 |
| Flash-Lite k = 8 正序 | +0.2 [−0.9, +1.2] | 218 | 224 |
| Flash-Lite k = 8 倒序 | +1.0 [−0.2, +2.2] | 179 | 216 |
| Qwen k = 4 正序 | **−1.0 [−1.8, −0.1]** | 106 | 76 |
| Qwen k = 4 倒序 | −0.5 [−1.6, +0.6] | 108 | 92 |
| Qwen k = 8 正序 | −0.7 [−1.7, +0.4] | 92 | 68 |
| Qwen k = 8 倒序 | −0.1 [−1.3, +1.1] | 129 | 127 |

- 八格中只有兩格的區間不含 0(Flash-Lite k = 4 倒序、Qwen k = 4 正序,都是下降約 1 pt),其餘六格的方向有正有負,看不出一致的影響。

## 5.5 error 內容的誤報

**結論:** 沒有錯的步驟被說成有錯的比例,在兩個模型都隨題數下降(大部分題型),與 Q1、Q2 的發現一致:題數越多,模型越傾向答「沒有錯」。

沒有錯的步驟被回答成「有錯」的比例,k = 1 → 4 → 8:

| 題型 | Flash-Lite | Qwen |
| --- | --- | --- |
| bool | 27% → 18% → 21% | 19% → 16% → 19% |
| single | 12% → 16% → 13% | 32% → 12% → 8% |
| multi | 33% → 13% → 16% | 32% → 14% → 9% |
| int | 42% → 20% → 14% | 4% → 1% → 0% |
| open_text | 31% → 23% → 18% | 21% → 13% → 7% |

- 這和幻覺率的方向對 Qwen 不一致:Qwen 誤報下降、幻覺上升,表示它整體更「有信心」地給出一個答案(「沒有錯」或對沒做的步驟給具體答案),而不是一律更保守。
- Flash-Lite 則是整體更保守:誤報下降、誤判沒做上升、幻覺下降。

## 限制

1. Argon 沒有跑這些題組,只有兩個模型。
2. 跨 k 比較只用同一批沒做步驟,但各 k 的題數不同(E5 尤其少);同一個沒做步驟出現在多個題型,題目不獨立,我用依錄影 bootstrap 處理。
3. 幻覺率會受提示中 `not_visible` 的措辭影響(Flash-Lite 第一次跑時 multi_choice 的措辭還不在提示裡,後來重跑,見 Flash-Lite 的 README)。
4. Flash-Lite 的 err multi 有 33 題格式錯誤,有效答案只有 75 題。
5. 沒有分析沒做的步驟在食譜中的位置(見 5.3)。
6. 沒有多重比較校正。
