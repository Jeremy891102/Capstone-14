# Q2:同一個事實換題型問,準確率會不會改變?

模型:Gemini 3.5 Flash-Lite、Qwen3-VL-32B、Gemini 4 Argon(Argon 只有 duration、localization 的 5 格)。資料:`cc4d_answer_types_v1` 的 base 組,k = 1(E1,每次 call 只問一題)。
腳本:`results/cc4d_q2.py`;完整輸出:`results/cc4d_q2_out.txt`。

## 大綱與結論

| 子問題 | 結論 |
| --- | --- |
| 2.1 換題型後,校正後的準確率是否不同? | **會,方向看內容和模型。** error 內容裡幾乎沒有題型能超過基線;duration 的 seconds 比 bool 差很多;localization 的 single 在三個模型都比 bool 好 |
| 2.2 差異是能力不同還是答案偏誤? | **主要是偏誤。** error 內容的準確率幾乎全來自「沒有錯」的步驟;有錯的步驟,所有題型答對率都不到 33%。換題型改變的是模型說「沒有錯」的傾向 |
| 2.3 各模型的結論是否一致? | **不一致**(模型 × 題型交互 p < 0.0001)。同一個題型在不同模型表現相反,例如 localization 的 seconds 相對 bool:Flash-Lite 較好,Qwen 與 Argon 較差 |
| 2.4 同一個事實在不同題型上,答對與否是否前後一致? | **只有一點點一致。** 整體相關約 0.1 到 0.5,但大部分來自「有錯 / 沒錯」本身的偏誤;扣掉之後只剩 0.16 到 0.32 |

**一句話總結:** 換題型確實會改變準確率,但在 error 內容裡改變的主要是模型回答「沒有錯」的傾向,不是看影片的能力;各模型的題型排名也不一樣,看不出普遍的「某種題型比較好」。

## 方法

- 用 k = 1 的資料(E1)。每個事實在每種題型各問一次,各自獨立呼叫。三種內容的事實在題型之間用 (錄影, 事實編號) 配對,我確認過同一事實在各題型指向同一個步驟。
- **哪些題型能算「同一個事實」:**
  - error:5 種題型(bool、single、multi、int、open_text)問的都是同一個步驟有沒有錯、錯了什麼。
  - duration、localization:只比 bool、single、seconds,三者問的是同一個步驟的時間,但不完全是同一件事(例如 bool 問「超過 31 秒嗎」,seconds 問「幾秒」)。multi 和 int 一次問 8 個步驟,不是一步一題,所以不放進來。
- **校正後準確率:** (準確率 − 基線) / (1 − 基線)。0 代表只達到基線,1 代表全對,負數代表比基線差。基線取亂猜與「一律答最多的答案」兩者的較大值,同一個事實在每個題型有相同的基線。
  - error 基線是 50%(題目設計成一半有錯一半沒錯);seconds 的基線是「事後挑最佳常數答案」,是上界,所以 duration seconds 的負值偏嚴苛。
- **信賴區間:** 依錄影 bootstrap 2,000 次。與 bool 的差是同一事實配對後的差。
- **回歸(只用在 2.3):** 邏輯斯回歸,依變項 `y` = 是否答對;解釋變項 `model`(三個模型)、`type`(題型)、`model × type`,duration 與 localization 另放 `content`。標準誤依錄影群集。
- 沒有做多重比較校正。

## 2.1 校正後準確率與題型

**結論:** 換題型會改變校正後的準確率,但方向看內容和模型。error 內容幾乎沒有題型能超過基線;duration 的 seconds 在 Flash-Lite 和 Qwen 都低於基線;localization 的 single 在三個模型都比 bool 好。

![q2_type_norm](figs/q2_type_norm.png)

(0 = 只達到基線答案,1 = 全對。虛線是基線。)

**error(Flash-Lite 與 Qwen):**

| 題型 | Flash-Lite | 與 bool 的差 | Qwen | 與 bool 的差 |
| --- | --- | --- | --- | --- |
| bool | +0.05 [−0.02, +0.13] | — | −0.07 [−0.15, +0.00] | — |
| single | +0.02 [−0.05, +0.09] | −0.04 | +0.01 [−0.08, +0.09] | +0.08 |
| multi | −0.11 [−0.20, −0.01] | **−0.16** | −0.06 [−0.14, +0.02] | +0.02 |
| int | −0.26 [−0.33, −0.20] | **−0.32** | +0.04 [−0.01, +0.07] | **+0.11** |
| open_text | −0.19 [−0.25, −0.12] | **−0.24** | −0.19 [−0.25, −0.12] | **−0.11** |

- 沒有任何題型的校正後準確率明顯高於 0。Flash-Lite 的 multi、int、open_text 比「一律答沒有錯」還差。
- 題型之間:Flash-Lite 的 multi、int、open_text 都比 bool 差;Qwen 的 int 比 bool 好,open_text 比 bool 差。

**duration 與 localization:**

| 內容 / 題型 | Flash-Lite | Qwen | Argon |
| --- | --- | --- | --- |
| dur bool | +0.10 | +0.25 | +0.79 |
| dur single | +0.11(與 bool 差 +0.02) | +0.21(−0.04) | +0.66(**−0.14**) |
| dur seconds | −0.13(**−0.22**) | −0.16(**−0.41**) | 沒跑 |
| loc bool | −0.03 | +0.49 | +0.89 |
| loc single | +0.13(**+0.16**) | +0.81(**+0.32**) | +0.96(**+0.07**) |
| loc seconds | +0.21(**+0.24**) | +0.31(**−0.18**) | +0.71(**−0.18**) |

(括號內是與 bool 的校正後差距,粗體代表區間不含 0。)

- localization 的 single 比 bool 好,在三個模型都一致。
- seconds 與 bool 的比較在 localization 上方向相反:Flash-Lite 的 bool 本來就在亂猜線上(−0.03),所以 seconds 看起來較好;Qwen 與 Argon 的 bool 很高,seconds 較差。

## 2.2 差異是能力還是偏誤:error 內容拆開看

**結論:** 主要是偏誤。error 內容裡,所有題型的準確率都幾乎全來自「沒有錯」的步驟;有錯的步驟,任何題型的答對率都不到 33%。換題型改變的是模型說「沒有錯」的傾向。

![q2_err_split](figs/q2_err_split.png)

| 模型 / 題型 | 有錯的步驟答對 | 沒錯的步驟答對 |
| --- | --- | --- |
| Flash-Lite bool | 32.0% | 73.4% |
| Flash-Lite single | 13.7% | 87.9% |
| Flash-Lite multi | 22.3% | 67.2% |
| Flash-Lite int | 16.0% | 57.8% |
| Flash-Lite open_text | 12.5% | 68.8% |
| Qwen bool | 11.7% | 80.9% |
| Qwen single | 32.8% | 68.0% |
| Qwen multi | 26.2% | 68.0% |
| Qwen int | 7.8% | **95.7%** |
| Qwen open_text | 2.0% | 79.3% |

- 兩組各 256 題。如果一律答「沒有錯」,有錯的步驟答對率是 0,沒錯的步驟是 100%。表中的數字全部偏向「沒有錯」那邊。
- 最極端的是 Qwen 的 int:沒錯的步驟答對 96%,有錯的只有 8%,幾乎一律答 0。
- Qwen 的 single 是唯一有錯的步驟答對率較高(33%)的題型,代價是沒錯的步驟答對率降到 68%。

**duration / localization 的 bool:回答「是」的比例(k = 1)**

| 模型 / 內容 | 真答案是「是」時答是 | 真答案是「否」時答是 |
| --- | --- | --- |
| Argon dur | 90% | 8% |
| Argon loc | 94% | 2% |
| Qwen dur | 40% | 6% |
| Qwen loc | 66% | 7% |
| Flash-Lite dur | 21% | 7% |
| Flash-Lite loc | 14% | 16% |

- Argon 能分辨(是的時候答是、否的時候答否)。
- Qwen 的 dur 是偏向答「否」(真答案是「是」時只答對 40%)。
- Flash-Lite 在 loc 的 bool 幾乎沒有分辨力:不管真答案是什麼都只有 14 到 16% 答是。

## 2.3 各模型的題型排名是否一致

**結論:** 不一致。模型 × 題型的交互在兩組都顯著。同一個題型,在不同模型上表現可以相反。

| 檢定 | 範圍 | χ² | 自由度 | p |
| --- | --- | --- | --- | --- |
| 模型 × 題型 | duration + localization(bool、single、seconds,三個模型) | 93.6 | 4 | < 0.0001 |
| 模型 × 題型 | error(5 種題型,Flash-Lite 與 Qwen) | 74.0 | 4 | < 0.0001 |

- 例子:error 的 int,Flash-Lite 是最差(與 bool 差 −0.32),Qwen 反而是最好(+0.11)。localization 的 seconds,Flash-Lite 比 bool 好,Qwen 與 Argon 比 bool 差。
- 共同點只有兩個:localization 的 single 比 bool 好(三個模型),duration 的 seconds 比 bool 差(Flash-Lite 與 Qwen)。
- 這個檢定問的是「題型排名是否因模型而異」,不是哪個題型比較好。

## 2.4 同一個事實在不同題型上,答對與否是否前後一致

**結論:** 只有一點點一致。error 內容整體的相關看起來不低(0.45 到 0.53),但大部分來自「有錯 / 沒錯」本身(模型常答沒有錯,所以沒錯的步驟全部答對、有錯的全部答錯)。把兩組分開看,相關只剩 0.16 到 0.32。

指標:同一個事實在每種題型的「答對 / 答錯」兩兩算相關係數(phi),再對所有題型配對取平均。

| 模型 | error 全部 | 只看有錯的步驟 | 只看沒錯的步驟 | duration | localization |
| --- | --- | --- | --- | --- | --- |
| Flash-Lite | 0.45 | 0.16 | 0.32 | 0.29 | 0.11 |
| Qwen | 0.53 | 0.25 | 0.29 | 0.30 | 0.15 |
| Argon | 沒跑 | 沒跑 | 沒跑 | 沒跑 | 0.28 |

- 即使分開看,多數相關仍然是正的。這代表有些事實(例如錯誤特別明顯的步驟)在各種題型上都比較容易答對,不是各題型各自亂猜。
- 幅度很小。模型不是「看懂了就在所有題型都答對」。
- duration 與 localization 的題型問的不是完全相同的事,所以這裡的相關只能當參考。
- 我沒有對這個相關算信賴區間。

## 限制

1. 只用 k = 1。題型與題數的交互在 Q1 第 3 節已做過(duration、localization 不顯著)。
2. error 的基線是 50%(題目設計成一半有錯一半沒錯);seconds 的基線是「事後挑最佳常數答案」的上界,所以 duration seconds 的負值偏嚴苛。
3. duration、localization 的 bool / single / seconds 不是完全相同的事實,只是同一個步驟的時間,比較時要保留。
4. open_text 由 `gemini-3.5-flash-lite` 評審,與 100 題人工標註一致率 78%,偏嚴,可能低估 open_text。
5. Flash-Lite 的 seconds 評分器 `typed_v3` 是看過結果後才定的。
6. Argon 只有 duration、localization 共 5 格,沒有 error、沒有 duration seconds。
7. 2.4 的相關沒有信賴區間;所有檢定都沒有多重比較校正。
