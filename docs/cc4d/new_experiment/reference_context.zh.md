# 參考題 × 影片對照:加 7 題參考題,是不是要有影片才有用?

模型:Gemini 4 Argon、Qwen3-VL-32B。對應隊友的 HD-EPIC 實驗,設計見 [reference_context_design.zh.md](reference_context_design.zh.md)。
腳本:`results/cc4d_reference.py`(輸出 `cc4d_reference_out.txt`)。建資料:`scripts/build_cc4d_reference.py`。設定:`experiments/cc4d_ref/`。逐題評分:`results/cc4d_reference_v1/`。

## 做法

- 目標題:64 支錄影、每支在是非 / 多選 / 秒數各抽 8 題,共 **1,528 題**。每次呼叫只回答 1 題目標題並只計分這一題。
- 參考題:目標題所在 k = 8 批次的其餘 7 題,只當背景,不回答。
- 四個條件:{只問目標題, 目標題 + 7 題參考} × {有影片, 無影片},共 8 組(2 個模型)× 1,528 次,全部成功。
- **D = (有影片的參考題增益) − (無影片的參考題增益)**,依目標題配對,依錄影 bootstrap 10,000 次。D 為正才表示參考題搭配影片更有用。
- 所有題目都允許回答 `not_visible`(同 k32 實驗)。

## 結論

- **Argon:加參考題沒有幫助,也沒有證據顯示它在有影片時更有用。** 整體 D = +1.0 [−2.3, 4.3],區間跨 0。有影片、無影片都略降(−2.3、−3.3)。這和隊友 HD-EPIC 的結果方向相反(她是兩邊都 +8 pt)。
- **Qwen(允許 `not_visible`):回答不了這個問題。** 無影片時它幾乎一律答 `not_visible`,準確率反映的是棄答率,不是參考題的資訊效果。
- **Qwen(拿掉 `not_visible` 重跑):D = +1.2 [−1.0, 3.6],區間跨 0。** 沒有證據顯示參考題在有影片時更有用;而且 Qwen 有影片的準確率(31.8%)比無影片(36.4%)還低,見「Qwen:拿掉 `not_visible` 重跑」一節。

## Argon

準確率 %,括號為加參考題的變化。

| 題型 | 題數 | 有影片 單題 → +參考 | 無影片 單題 → +參考 | D [95% 區間] |
| --- | --- | --- | --- | --- |
| 全部 | 1,528 | 61.3 → 59.0(−2.3) | 34.4 → 31.1(−3.3) | +1.0 [−2.3, 4.3] |
| 是非 | 510 | 69.2 → 64.1 | 56.3 → 51.0 | +0.2 [−6.4, 6.7] |
| 多選(什麼錯誤) | 510 | 50.2 → 48.4 | 22.5 → 26.7 | −5.9 [−11.4, −0.2] |
| 秒數 | 508 | 64.4 → 64.4 | 24.2 → 15.6 | +8.7 [3.5, 14.0] |

- 秒數的 D 為正,是因為**無影片時加參考題讓秒數掉了 8.7 pt**(`not_visible` 54 → 77 題),有影片時沒變。這不是「有影片時參考題更有用」。
- 多選的 D 為負,區間貼近 0。三種題型各檢定一次,沒有多重比較校正,只當線索。
- 排除棄答後(只留四個條件都沒答 `not_visible` 的 1,390 題),結論不變:整體 D = +1.2 [−2.4, 4.7],秒數 +9.8 [3.5, 16.3]。所以 Argon 的結果不是棄答造成的。

## Qwen3-VL-32B

| 題型 | 有影片 單題 → +參考 | 無影片 單題 → +參考 | D [95% 區間] |
| --- | --- | --- | --- |
| 全部 | 30.2 → 32.8 | 14.2 → 20.5 | −3.8 [−5.8, −1.8] |
| 是非 | 45.9 → 51.4 | **0.4** → 19.6 | −13.7 [−18.6, −8.9] |
| 多選 | 29.0 → 31.0 | 42.2 → 40.4 | +3.7 [0.4, 7.1] |
| 秒數 | 15.7 → 15.9 | **0.0** → 1.6 | −1.4 [−4.2, 1.4] |

- **無影片單題時 Qwen 對是非題 503/510、秒數題 508/508 答 `not_visible`**,準確率因此是 0.4% 和 0.0%。加了參考題後是非題的 `not_visible` 降到 316/510,準確率跳到 19.6%。這個 +19 pt 只是「比較不棄答」,所以 D = −13.7 不能解讀成影片或參考題的效應。
- 排除棄答後,四個條件都沒棄答的只剩 517 / 1,528 題,其中 510 題是多選題,是非題只剩 7 題,秒數題 0 題。剩下的多選題 D = +3.7 [0.4, 7.1],但無影片單題準確率 42.2% 已接近「固定答最常見答案(沒有錯)」的上限 44.9%,更像答案偏誤。

## 限制

1. **目標題位置和格式與隊友不同:** 目標題固定排在參考題後面(她保留原位置);參考題只有題目與選項,沒有答案格式說明。D 量的是整個協定的差異,不是純粹題目語意。
2. **允許 `not_visible`:** 無影片時會大幅改變準確率,Qwen 尤其明顯。因此 Qwen 另跑了一版不允許 `not_visible` 的設定(見「Qwen:拿掉 `not_visible` 重跑」一節);Argon 沒有重跑(它的棄答率低,且排除棄答後結論不變)。
3. **各題型是三次獨立檢定,** 沒有多重比較校正,區間貼近 0 的只當線索。
4. **區間跨 0 不代表沒有差別。**
5. 有影片 / 無影片兩邊是同期跑的(和隊友的 HD-EPIC 不同,她的有影片資料是舊的)。
6. **費用:** Argon 小測試單次呼叫約 $0.002(無影片)到 $0.017(有影片 + 參考);全量實際花費尚未統計。

## Qwen:拿掉 `not_visible` 重跑

同樣的 1,528 個目標與參考組,所有題目不允許 `not_visible`,答案格式提示也拿掉(`--no-nv`,設計見設計文件最後一節),Qwen 4 組各 1,528 次全部成功。

| 題型 | 有影片 單題 → +參考 | 無影片 單題 → +參考 | D [95% 區間] |
| --- | --- | --- | --- |
| 全部 | 31.8 → 33.2(+1.4) | 36.4 → 36.6(+0.2) | +1.2 [−1.0, 3.6] |
| 是非 | 46.1 → 51.0 | 47.1 → 48.0 | +3.9 [−0.8, 8.6] |
| 多選 | 33.1 → 32.9 | 44.1 → 42.0 | +2.0 [−1.6, 5.5] |
| 秒數 | 16.1 → 15.7 | 17.9 → 19.7 | −2.2 [−5.6, 1.2] |

- **所有 D 的區間都跨 0。** 拿掉 `not_visible` 後,第一輪的 D = −13.7(是非)消失,證實那是棄答率造成的。
- **無影片時 Qwen 靠固定答案:** 單題時是非題 423/510 答「做對了」(83%;實際只有 54%),多選題 474/510 答「沒有錯」(93%),秒數題 168/508 答 15 秒。準確率因此是 47.1%(是非)、44.1%(多選),貼著固定答案上限(54.3%、44.9%)。
- **有影片的 Qwen 反而比無影片差:** 單題時 31.8% < 36.4%(多選 33.1 < 44.1)。有影片時它較少答「沒有錯」(162/510),改答具體錯誤(如 C 126 題),但答對的不多,所以輸給「一律答沒有錯」的策略。這和 novideo 實驗的發現一致:Qwen 看影片的增益很小。
- 加參考題也會改變固定答案的比例:無影片是非題「做對了」423 → 302,多選「沒有錯」474 → 438,準確率變動主要來自這裡,不是新資訊。
- 兩輪的準確率不能直接相減(差本身就是「允許棄答」的效果)。

## 和 HD-EPIC 的對照

| | HD-EPIC(隊友,73 支 / 2,336 題,Argon) | CC4D(Argon,64 支 / 1,528 題) |
| --- | --- | --- |
| 有影片 單題 → +參考 | 60.02 → 67.29 | 61.3 → 59.0 |
| 無影片 單題 → +參考 | 26.54 → 34.97 | 34.4 → 31.1 |
| 有影片的參考題增益 | +7.28 pt | −2.3 pt |
| 無影片的參考題增益 | +8.43 pt | −3.3 pt |
| D | −1.16 [−4.20, +1.80] | +1.0 [−2.3, 4.3] |
| 影片本身的增益(單題 / +參考) | +33.5 / +32.3 pt | +26.9 / +27.9 pt |

(HD-EPIC 數字來自隊友的完整 73 支結果,D 與區間為她的回報;她先前 10 支 / 320 題的子集是 D = −0.3 [−6.6, 5.9],方向相同。)

兩邊的 D 都接近 0、區間跨 0:都沒有證據顯示參考題在有影片時更有用。不同的是參考題本身:HD-EPIC 無論有沒有影片都有幫助(約 +7 到 +8 pt),所以 k = 1 到 8 的批次增益不能只歸因於更好地使用影片;CC4D 的參考題沒有幫助。隊友也指出這個實驗無法區分參考題文字是提供有用的背景,還是洩漏了答案線索。HD-EPIC 的題目是單一題型(5 選 1),CC4D 是三種題型,答案格式與題目文字的線索量不同,所以不能直接推論到同一個機制。
